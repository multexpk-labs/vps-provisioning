# VPS Networking

Provisioning may involve:

- IPv4/IPv6 allocation
- Private networks
- Gateways
- DNS
- Reverse DNS
- Firewall/security groups
- Routing
- Interface configuration

## Validation

Check that:

1. The allocated address belongs to the expected resource.
2. The gateway and routes are correct.
3. DNS records resolve as intended.
4. Required service ports are reachable.
5. Unnecessary ports remain closed.

Keep address pools and production inventories out of public repositories.
